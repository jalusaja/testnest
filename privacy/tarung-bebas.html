Kebijakan Privasi — Tarung Bebas

Berlaku sejak: 4 November 2026

Kebijakan ini menjelaskan data apa yang diproses oleh game Tarung Bebas (nama paket com.stickninja.game) di Android, dan untuk apa.

1. Data yang kami simpan

Game ini tidak memiliki akun dan tidak meminta nama, email, nomor telepon, kontak, foto, atau lokasi Anda. Progres permainan (emas tabungan, level senjata, karakter, skor tertinggi, pengaturan suara) disimpan hanya di perangkat Anda dan tidak dikirim ke server kami. Data ini terhapus saat aplikasi dihapus atau saat Anda menekan "Reset Progres".

2. Iklan (Google AdMob)

Game ini menampilkan iklan berhadiah (rewarded ads) dari Google AdMob, hanya jika Anda memilih menonton iklan. Untuk menampilkan dan mengukur iklan serta mencegah penipuan, SDK Google Mobile Ads dapat mengumpulkan: ID iklan perangkat, alamat IP (perkiraan lokasi kasar), informasi perangkat dan sistem operasi, serta interaksi dengan iklan dan data diagnostik. Data ini diproses oleh Google sesuai Kebijakan Privasi Google dan cara Google menggunakan data dari aplikasi mitra. Anda dapat mereset atau menghapus ID iklan dan mengatur personalisasi iklan di Setelan Android > Google > Iklan.

3. Pembelian dalam aplikasi

Pembelian (misalnya Palu Godam, Pedang Laser, atau paket) diproses sepenuhnya oleh Google Play Billing. Kami tidak menerima atau menyimpan data kartu atau pembayaran Anda. Game hanya menerima konfirmasi produk yang dibeli agar dapat membuka isinya, dan menyimpan status tersebut di perangkat. Pemrosesan pembelian menggunakan Unity In-App Purchasing, yang dapat mengirim data teknis transaksi untuk keperluan fungsi pembelian.

4. Anak-anak

Game ini ditujukan untuk pengguna berusia 13 tahun ke atas dan tidak ditujukan untuk anak-anak. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak-anak.

5. Keamanan

Data yang dikirim oleh layanan pihak ketiga di atas dikirim melalui koneksi terenkripsi (HTTPS).

6. Penghapusan data

Karena tidak ada akun, Anda dapat menghapus semua data game dengan menghapus aplikasi atau memakai tombol "Reset Progres". Untuk data iklan, gunakan pengaturan ID iklan di perangkat Anda.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui. Perubahan akan dicantumkan di halaman ini beserta tanggal berlakunya.

8. Kontak

Pertanyaan tentang privasi: bangjalu@gmail.com

Privacy Policy (English summary)

Tarung Bebas has no accounts and does not ask for personal information. Game progress is stored only on your device. The game shows optional rewarded ads from Google AdMob, which may collect the advertising ID, IP address, device information, ad interactions and diagnostics (see the Google Privacy Policy). In-app purchases are processed by Google Play Billing; we never receive payment details. The game is intended for users aged 13 and over. Contact: bangjalu@gmail.com.
